# Screenshot assets

Drop production Playblast UI screenshots here as PNG files. The landing page gallery reads these paths directly — no code changes needed when swapping placeholders for real shots.

## Required files

| File | Suggested content |
|------|-------------------|
| `review.png` | Review player with timestamped comments |
| `compare.png` | Side-by-side version comparison |
| `annotate.png` | Frame annotation / markup view |
| `projects.png` | Projects and deliverables list |

## Specs

- Format: PNG
- Recommended size: 1280×800 or 16:10 equivalent
- No fake metrics, logos, or customer names in screenshots

Current files are dark slate placeholders generated by `scripts/gen-screenshot-placeholders.py`.
